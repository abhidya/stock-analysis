# stock-analysis

## Archive status

This is an archived Excel/VBA stock-analysis project. The macro-enabled workbooks are retained for portfolio review and should be opened only in a trusted local spreadsheet environment.

## Contents

- `green_stocks.xlsm` - original macro-enabled workbook.
- `VBA_Challenge.xlsm` - challenge workbook.

## Safety note

Because `.xlsm` files can contain macros, review workbook code before enabling macros on any machine.
